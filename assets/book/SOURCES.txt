Wanderstead travel stationery

Legacy breakfast illustrations, paper fibres, oak grain, leather binding and
copper fittings: original procedural artwork in tools/make_book.py.
The four chapter tool plates retain their original OpenAI generate_image
source at art/book/tool-plates-source.png; the adventure script reproducibly
crops silhouettes, preserves open holes, downsamples and quantizes them.
tools/make_adventure_book.py authors restrained oak/charcoal translucent rails,
brass-edged action buttons (seed 231122), nine transparent 24px command icons
and the 48px north compass. All icon pixels and compass lines are original
coordinates in that script; they are not commercial reference cutouts.
tools/make_book_road.py retains the earlier compact paper studies from the same
original paper grain and binding; the complete folio is used for modal pages.
The HUD glass has deliberate translucency; journal paper is opaque.
art/book/*reference.png are authoring/material sheets, NOT game screenshots.
No third-party game artwork or photographs are used.
The compact HUD uses a single day/place/goal line, a north compass with actual
grid coordinates, and a lower-left exploration map in BOTH town and B1.
The lower strip carries real HP, tonics, fruit and current expedition copper,
the two most recent distinct messages, and separate explicit danger copy.
Every command is labelled with its actual keyboard shortcut where one exists.
Hover a command for its effect or the reason it is unavailable. J opens the
reading-size controls guide; H toggles the roaming HUD. Modal pages stay visible.
Default text is 15 logical units for the HUD, 18.75 for reading, 22.5 for headings
(24 / 30 / 36 physical px at 2560x1440). BookTypography configures these sizes.
Runtime nodes, clickable controls and authoring sheets share HudPart geometry in
src/book.rs; art/book/ui-layout.json records the layout envelope. The message
strip fits its text. Floating labels pass clicks to the world. Modal pages use 760x700.
Maps reveal actual line-of-sight tiles and retain separate town/B1 session memory.
The compass remains north-locked, matching the camera. No artificial counters
or inert action slots are presented. Page::Barter remains an opaque modal trade.
The traveler portrait is supplied by the project's figures artwork.

Rebuild artwork: uv run --with pillow python tools/make_book.py
Rebuild compact rail only: uv run --with pillow python tools/make_book_road.py
Rebuild adventure materials: uv run --with pillow python tools/make_adventure_book.py
Glyph coverage: uv run --with fonttools python tools/make_book_glyphs.py
The glyph report checks all characters used by src/book.rs, src/game.rs,
src/delve.rs and src/controls.rs, and records the configurable type defaults.
