Wanderstead / 铜壶镇 · 第一股泉水 — original figure and market artwork

These character/prop designs were generated specifically for this repository with
OpenAI's generate_image tool (provider openai-codex, model gpt-image-2-codex,
catalog openai-codex/gpt-image-2), November 2026. No downloaded commercial game
sprites, traced game artwork, or third-party asset packs are included.

Original source images are retained in art/figures/source/:
- traveler-style.webp: original teal cloak, chestnut hair, russet backpack,
  linen shirt, tan trousers and leather boots; front / west / north style proof.
- traveler-walk.webp: 4 columns x 4 rows, south / west / north / east walk cycle.
- traveler-actions.webp: 4 x 3, gather / shake / overhand throw, west-facing.
- traveler-breakfast.webp: 4 x 1, lifting spoon / tasting / chewing, no bowl.
- keeper-work.webp: 4 x 2, innkeeper stirring batter / kneading dough.
- jelly-plum.webp: 4 x 3, leaf jelly hop / swallow / individual violet plums.
The WebP files record the earlier long-proportioned art pass. Current runtime
humans and enemies are newly drawn short-proportioned images, not flattened
versions of those figures:
- traveler-short-walk.png: 4 x 4 south / west / north / east walk poses.
- traveler-short-actions.png: 4 x 4 gather / shake / throw / breakfast.
- traveler-combat.png: 4 x 4 strike / brace / hurt and down / potion.
- keeper-short-work.png: 4 x 2 stirring / kneading, compact cook silhouette.
- copper-sentry.png: 4 x 4 idle / prepare / strike / collapsed copper armor.
- phosphor-moth.png: 4 x 4 idle / prepare / dive / fallen moth.
These six PNG sources were generated with the same OpenAI model on November
22, 2026. The user's town/ruin screenshots informed camera and short JRPG
proportions; no character pixels were copied from those screenshots.

The herbalist and the eight market/ruin furnishings are original generate_image
artwork for the same chapter. Sources: art/market/herbalist-source.webp and
furnishings-source.webp. The latter includes the herb jar, flowers, basket and
old canal plants. Processing: tools/make_herbalist.py, tools/make_market_atlas.py
and tools/bake_market_dressing.py (Blender 4.5). The square's original study of
sixteen single flagstones is in art/lane/town-single-flags-source.png;
tools/make_lane.py reduces it in linear colour before assigning one slab to each
walkable square. All use the same service terms as the character artwork.

Processing source: tools/make_figures.py, Pillow >= 10. Run from repository root:
  python tools/make_figures.py
The script removes generated background mattes and edge chroma artifacts,
uses one uniform scale per animation and stable sole pivots, quantizes the
complete set to a shared 96-color palette, hardens alpha, and exports padded
atlases under assets/figures/. It is offline and reproducible from retained inputs.
The procedural soft contact shadow is also generated by that same source script.
Exact layouts, pivot pixels, directions and frames: art/figures/atlas-layout.json.
Art inspections: art/figures/traveler-sample.png, contact-sheet.png and
silhouette-check.png. Red ticks in contact/silhouette sheets mark foot pivots.
The portrait is cropped from the original new traveler's head artwork.
These are source-art previews, not game screenshots.

Runtime integration: src/figures.rs. All required runtime images are in the
repository; no network, external account, or generation tool is needed to play.
Atlas meshes are GPU-only after upload. Each sheet retains its finite local
quad AABB, which every spawned body, shadow caster and fruit card receives
explicitly. This also covers actors created after a region transition.
With --qa enabled, F10 logs the actor/card ECS visibility, finite bounds,
transforms, materials and texture loading after visibility propagation.
